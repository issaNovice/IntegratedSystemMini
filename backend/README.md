
Create a .env file and replace the values with your database details:

DB_HOST=localhost
DB_PORT=3306
DB_USER=user_name
DB_PASSWORD=your_password
DB_NAME=sakila
PORT=4000
JWT_SECRET=your_token

install the following dependencies:

    nodemon
    bcryptjs
    cors
    dotenv
    express
    jsonwebtoken
    morgan
    mysql2

Start:
- npm run dev
